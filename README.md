# COSMOS — cinematic 60-second short

A self-contained, procedurally generated space film. No paid video-generation API or external assets are required.

## What it renders
- 60 seconds, 1920×1080 (16:9), 24 fps
- Six original space tableaux: nebula, ringed planet, gas giant, lunar horizon, Earthrise, spiral galaxy
- Slow cinematic camera moves, cross-dissolves, title cards and an original synthesized ambient score
- MP4 (H.264 video + AAC audio)

## Render locally
Requirements: Python 3.11+, Pillow, NumPy, and FFmpeg with libx264, aac, and xfade support.

    python -m pip install -r requirements.txt
    python render.py

Output: dist/cosmos-60s.mp4.

## Render on GitHub
The workflow runs on every push to main, and can also be started manually from Actions → Render COSMOS film → Run workflow. The finished MP4 is uploaded as the cosmos-60s-video artifact for 14 days.

## Creative notes
All imagery and music are generated by the project itself. The film is an artistic interpretation of space, not scientific visualization.
